# 안녕하세요, 주니어 AI 엔지니어입니다 👋

> 🌱 신입·주니어 AI 엔지니어 포지션을 찾고 있습니다.

안녕하세요. 데이터로 문제를 발견하고 AI로 해결하는 주니어 AI 엔지니어를 꿈꾸며 구직 중입니다. Python과 SQL을 바탕으로 데이터 전처리와 분석, 머신러닝 모델 구현을 공부하고 있습니다. 프로젝트도 문제 정의부터 결과 검증까지 끝까지 완성하며 배운 내용을 기록합니다. 읽기 쉬운 코드와 재현 가능한 실험을 지향하고, Git으로 협업하는 습관을 기르고 있습니다. 피드백을 반영하며 팀과 성장하고, 사용자에게 가치를 주는 AI 서비스를 만들고 싶습니다.
